# Admin UI Improvements Spec

## Overview
Redesign and improve the admin dashboard interface for better usability when managing textbooks and their lessons.

## Scope
- Admin dashboard navigation restructuring
- Textbook upload interface (grade + medium selection)
- Lesson management page (edit, delete, question bank)
- Question review and approval workflow

## Key Features
1. **Admin Dashboard Navigation** - Clean sidebar/navbar with: Dashboard, Upload Textbooks, Manage Questions, Manage Students, Logout
2. **Textbook Upload UI** - Grid of grade boxes (6-11) with medium buttons (Sinhala/English)
3. **Lesson Management** - Per-lesson controls: edit title, edit page ranges, delete, manage questions
4. **Question Review** - Accept/reject interface with image generation options
